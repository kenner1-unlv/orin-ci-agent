# Project diagrams

Place generated project artwork here. The top-level README is prepared for:

- `workflow-overview.png`: end-to-end task, worker, sandbox, review, CI, and commit flow.
- `trust-boundaries.png`: permissions held by the Orin worker, reviewer, CI promoter, and human operator.
- `job-lifecycle.png`: requested, running, completed, imported, reviewed, and promoted states.

Prefer wide 16:9 or 2:1 images with readable labels on both light and dark GitHub themes. Avoid credentials, IP addresses, hostnames, or other machine-specific data.
